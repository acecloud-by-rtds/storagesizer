# StorageSizer

Static Tailwind CSS website with five functional storage calculators and 25 flat-file guides.

## Preview locally
Extract the ZIP and open `index.html` in a browser. Internal links use relative file paths so the site also works when opened directly from the filesystem. Styling loads from the Tailwind CDN, so an internet connection is required for the CSS during local preview.

## Guide URL structure
Guides are flat files inside `/guides/`, for example:
`/guides/iops-vs-throughput-vs-latency.html`
